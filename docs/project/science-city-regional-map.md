# 未来科学城大地图 · 楼位与立面复核

「总览」和「项目分布」共用 MoonTown 街区画布。「项目分布」选择楼盘或园区后，镜头平移到对应建筑。历史链接 `?view=region` 进入同一画布，项目直达使用 `?view=overview&district=robotics`。3D 研究在当前地图上打开，浏览器前进、后退按访问记录恢复镜头。

## 本轮修订

- 34 项住宅、产业或入驻目录加未来中心共 35 个项目。两座桥单列。未来科创中心使用绿地云谷中心，合成生物孵化区对应未来公元和中铝科创园。
- 426 个普通建筑体量、未来中心 7 个单体和未来视界 6 个模型部件，共 439 个建筑体量。原街区在水面、道路、重叠和画面边界校验后显示其中 214 个普通体量，分属 15 个项目。加上未来中心与未来视界，原镇有 17 个项目具备独立建筑。区域相机单独烘焙十组投影，跨河车辆画在桥面和桥的前缘之间。
- [40 个逐栋轮廓修订](science-city-footprint-revisions.json)采用匹配到的 Overture / OpenStreetMap 建筑外圈。常规修订要求候选唯一，原交并比至少 0.55、中心距不大于 6 米。另复核原先越界的 3 栋，采用完整落在对应组团的实有参考轮廓。鲁疃嘉园两栋重新进入街区，北四村一栋进入区域图。7 个体量采用匹配参考要素的高度字段，其精度取决于图源。
- 云谷中心另有一栋原先只盖住院心，按影像重描外围与中庭，楼顶、天井和 3D 共用轮廓。逸园 9–12 号楼按房源附件的具体单元层数与编号鸟瞰图改变天际线，分别为 5/5/7、4/6/6/6、4/6/6/6、4/7/7/7 层。低段所在端按鸟瞰，段宽等分近似。窗洞宽度参考开发商户型说明。
- 旧审查的 468 条记录中，仍有 29 个缺乏可靠归属或越界的候选及 1 个开敞地候选。它们保留在审查记录。逐栋现状四向照片不齐，大地图在楼栋资料中区分已定位实景、项目级实景、公开设计和研究推定。

## 数据与复现

底图来自本地北京 OSM PBF，包含土地利用、水域、道路、桥梁和背景建筑。浏览器使用离线矢量包，地图请求不会把浏览的项目或坐标传给第三方。区域画面使用东、南米制坐标和同一正交相机。植栽、模型灯光和车流是场景表达。[Geofabrik 北京数据](https://download.geofabrik.de/asia/china/beijing.html) · [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) · [Overture 建筑与归属](https://docs.overturemaps.org/attribution/) · [土沟部分轮廓的东亚建筑数据](https://doi.org/10.5281/zenodo.8174931)

1. 从仓库根目录运行 `moon run scripts/import-science-city-region.mbtx output/science-city/beijing.osm.pbf` 生成区域底图，随后运行 `moon run scripts/compile-science-city-sites.mbtx`。项目与每栋证据有稳定 ID。
2. 模型或相机发生变化时，先更新可访问的本地建筑预览，再运行 `moon run scripts/bake-science-city-landmarks.mbtx <预览地址> <Playwright 的 index.mjs 绝对路径>`。版本校验覆盖几何、材质、相机轴和烘焙器。
3. 运行 `scripts/build-rabbita-ui.sh` 打包。生产检查保留原 73 MiB 的小镇与查看器预算，按需加载的全域附加资源单独约束在 1.25 MiB。建筑与背景仅在相机改变时重画，车流使用独立画层，支持暂停和系统减少动态偏好。
