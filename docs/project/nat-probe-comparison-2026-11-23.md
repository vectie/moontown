## 后续排障注意

1. “端口映射列表看起来正确”和“运行中的回流路径正常”需要分别验收；外网成功不能替代独立 LAN 客户端与目标主机自身的回流测试。
2. 新增诊断规则后其他入口恢复时，必须删除诊断规则并复测。本次删除立即复现故障，不能在临时规则仍在时宣告完成。
3. 不要因旧 `.175` 字样就扩大权限。已发现的 NFS 白名单只管 2049，并不解释 443/8443/32123 同时失效。
4. 本次恢复并不证明长期不会复发。若再发生，先保留 NAT 配置和操作日志，记录是否在规则增删后出现，再做有记录的正式规则重新保存；不要盲目重启服务器或清空防火墙。
