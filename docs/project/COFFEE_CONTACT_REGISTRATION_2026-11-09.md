# 活动注册与来源归因

用户目标：半醒工坊保留原稿上下结构；参赛注册只填写手机号或邮箱中的一个，以及至少六位密码。

## 行为

- 咖啡页登录框隐藏可选昵称，注册默认展示名为“创作者”。手机号规范化为 `+86` 中国大陆号码，邮箱沿用统一账户。
- 密码不再要求大小写、数字、符号组合。沿用统一身份网关和账户会话，不在活动站保存密码。
- 游客生成、IndexedDB 作品和草稿、登录认领逻辑保持原实现；来源代码不访问或清理这些缓存。
- 首次进入活动页保存来源 Cookie，30 天有效，后续直接访问不覆盖首次来源。后台记录 `acquisition_source/campaign/entry`；外部引用仅保留主机名，不收集路径、查询参数。
- 展示页二维码为 `display-qr`，手机直接按钮为 `display-direct`，普通活动访问为 `activity-direct`，外部引用为 `external-referral`；未提供来源的旧账户显示 unknown。
- 来源由客户端提供，是运营统计信息，不能作为角色、参赛资格或授权依据。它表示浏览器首次记录入口，并非可靠证明某人实际扫码。
- 后台通过统一身份系统的管理员属性查看来源，可用 LunaNexa `scripts/coffee-contact-release.mbtx report` 导出私有记录和来源汇总。当前未新增活动内获客仪表盘。
- 手机号注册使用密码登录，没有短信验证；后台保存 `phone_number_verified=false`，不伪造邮箱。
