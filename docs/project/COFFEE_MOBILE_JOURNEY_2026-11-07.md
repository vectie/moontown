## 本轮修复

1. 活动页内登录/注册，使用原 `/user/auth/*` 身份服务，不新建密码系统。
   首次注册可遇到 TrialProvisioningPending；注册 503 后最多尝试一次正常登录恢复，
   不重复创建账户或调用出图。新注册回归用户已验证成功。
   通用门户自身的试用初始化问题仍由 LunaNexa 负责，本轮没有宣称修好了试用资源服务。
2. 主办首屏增加审核入口；待审列表前置；投票与奖项设置折叠。
   点击入口后，实测工作台顶部约 32px，待审卡约 149px；原待审卡约在 1131px。
3. 退回作品有明确复投按钮，保留名称、昵称和原图，公开确认重新勾选。
4. 提交生成时立即反馈；主办请求进行中禁用相关按钮；投票开始后禁用入口修改，
   未到时间的奖项操作禁用并说明条件，不让用户点击后才收到 403。
5. 投票阶段将入口移到首屏，隐藏已截止的提示词表单，保留自己的图片和投稿状态。
   首次状态尚未载入时禁用生成按钮，避免尚未绑定脚本时提交表单。
