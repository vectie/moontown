# MoonTown 第一轮功能与界面优化验收

日期：2026-10-26。依据[功能审计基线](README.md)，由五个 Agent 分别实施材料、业务建筑、研究协作、运维、空间链路，主 Agent 整合账户导航、状态切换、构建及浏览器验收。工作保持在 `main`；已有未提交的账户、网关和空间改动继续保留。

## 已实现

| 链路 | 现在的行为 |
| --- | --- |
| 失效入口 | 公共小镇不探测私有 Pack API；未连接、401/403/404、无能力时只显示简短状态与有效下一步，不渲染整屏无效表单。协作服务未连接且没有未保存草稿时，同样显示连接/创建资料研究入口。 |
| 业务真实性 | 删除固定政策置信度和人才匹配概率；业务状态不再由 tick 生成。明确区分示例、载入记录、未接入；示例 health 即使包含 accepted 计数也不冒充真实证据。 |
| 工作与成果 | 本地/私有工作环境统一为小镇、工作、成果、算力、账户；工作面板分工作、成果、待我处理。成果库移出高级，既有导入成果从同一入口打开。公共展示保持其只读入口。 |
| 研究流程 | 新建、复用、历史成果继续研究、验证假设、声明质疑回到同一个编辑器。开始/刷新/恢复随真实状态出现；终态不提供重跑。打开历史任务不自动收集或执行。 |
| 审核与草稿 | 工作区待处理不冒称个人待办；只有当前 operator 与 decision owner 精确匹配时显示“待我审核”计数。主导航同页切换保留草稿；替换草稿的操作先要求保存，过期回复被 generation 隔离。 |
| 材料发现 | 五种发现方式改为一次选择一种模式，保留各自草稿；共用“选择资料→整理问题→提交审阅”。高级保存原始 JSON、精确检索规则、引用和提交记录。 |
| 运维 | 待处理结果优先；建设计划和自动任务显示简短状态及下一步。调度 tick、原始 pipeline、修复/桥接记录进入上下文高级。显式诊断深链仍可用。 |
| 室内与地下 | 当前对象、工作位、工作状态前置；完整工作位/楼内目录折叠，去掉重复新工作。机柜/服务器/主板仍可下钻；未知遥测、物理位置未绑定和只读范围保持可见。 |
| 三维工具 | 默认保留环视、复位与对象选择；报告、俯视、灯光、剖切、原理流动及完整 Studio 从高级进入。报告先显示当前对象，规划估算与实测分开。 |
| 视觉与入口位置 | 沿用纸色、绿灰色、统一线性图标和现有模型。领域资料进入宿主高级菜单；宿主已有入口时隐藏重复悬浮按钮。常规成功反馈不再附带一个技术诊断区。 |

必填信息不会因为“简化”而变成隐含默认值：审阅人账户标识仍明确填写；知识册要求的缺口评估未完成或无效时自动展开，不默认填零。后端授权、租户/账户隔离、证据校验、审核、幂等及审计均保留。

| 账户与网关 | 账户/身份/算力及 federated 场景 27/27，网关 5/5 通过；不等于线上不同账户已重新验收。 |
| 查看器契约 | 原独立查看器的 22/19/58 个 DOM 目标及渲染绑定保留；新增空间高级收纳契约通过。 |
| 构建与接口 | `moon info`、MoonBit 格式化与 JS release 构建完成；没有新增公开 MoonBit 接口。静态发布包完整性验证通过，769 个文件、70.5 MiB，保留完整模型。 |
| 差异检查 | `git diff --check` 通过；移除了格式化带来的 197 个无关文件差异，保留既有 dirty 文件和本轮实现。 |

全量 UI 中有三项原生 picker/HTTP 场景在未配置外部验收环境时提前返回。框架将其计入通过，但本记录不将它们算作真实 provider、原生程序或生产业务的端到端验收。

浏览器使用独立的本地临时工作区，避免写入用户正在使用的工作数据。已检查：

- 成果和待处理深链直接打开对应面板，切换时 URL 与当前面板一致。
- 关注/研究/协作只展开当前创建方式；空成果不显示无用筛选器，服务未连接时不展示不可用编辑表单。
- 室内家具选择会选中对应语义工作位，页面仅保留一个新工作入口；电梯进入地下后可返回原楼。
- 地下从机房进入机柜、服务器、主板；对象选择、报告、高级原理示意与完整模型审阅仍可达。
- 报告明确显示未绑定和未实测；详情可以滚动访问，原有 3D 和画风保留。
- Pack 未接入时不显示五套发现表单；关闭后焦点回到宿主入口。

## 发布边界与后续

本轮完成代码、发布构建和本地验收；尚未提交、推送或部署至 8443。线上仍使用此前版本。正式账户登录、真实 A/B/admin 资源可见性及任务落机继续按[账户链清单](accounts.md)单独验收。

目前缺少可验证的审阅人选择接口，所以保留必要账户标识输入；后续可以接同源只读选择器，不能用显示姓名自动替代账户身份。真实 rack/U、Run→机器和传感器绑定仍是空间链未完成项；本轮没有通过展示连线来替代它们。
